# Codexa Lume

Landing page estática e independente da Lume, oferta da Codexa para clínicas de estética. O projeto usa somente HTML, CSS e JavaScript puros, além dos tokens e assets oficiais copiados da biblioteca `codexa-ui`. Não depende de framework, plataforma de hospedagem ou serviço de build externo.

## Desenvolvimento

- Rode `npm run serve` e abra `http://localhost:4173` para navegar pela página.
- Rode `npm run check` para validar o JavaScript.
- Rode `npm run build` para gerar a versão estática independente em `dist/`.

Também é possível publicar o conteúdo de `dist/` em qualquer hospedagem de arquivos estáticos.

O formulário valida os dados no navegador e prepara uma mensagem para o WhatsApp da Codexa. Não há envio automático nem armazenamento de dados.
