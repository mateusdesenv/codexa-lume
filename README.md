# Codexa Lume

Landing page estática da Lume, oferta da Codexa para clínicas de estética. O projeto usa HTML, CSS e JavaScript puros, além dos tokens e assets oficiais copiados da biblioteca `codexa-ui`.

## Desenvolvimento

- Abra `index.html` em um servidor local para navegar pela página.
- Rode `npm run check` para validar o JavaScript.
- Rode `npm run build` para gerar a versão publicável em `dist/`.

O formulário valida os dados no navegador e prepara uma mensagem para o WhatsApp da Codexa. Não há envio automático nem armazenamento de dados.
